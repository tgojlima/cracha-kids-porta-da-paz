# Crachá Kids Porta da Paz

Sistema web para geração de crachás personalizados do ministério infantil "Kids Porta da Paz". 

## 🚀 Funcionalidades
- Upload de foto do participante (com ajuste de zoom e posição).
- Inserção de nome.
- Seleção de versículo bíblico ou personalizado.
- Frase "Quem você é para Deus" personalizável.
- Visualização 3D (frente e verso).
- **Salvar múltiplos crachás** em uma galeria.
- Selecionar crachás para impressão em lote.
- Download em PNG em alta resolução (para impressão).

## 🛠️ Tecnologias
- HTML5
- CSS3 (Glassmorphism, Flexbox, Grid)
- JavaScript (Vanilla)
- HTML2Canvas (Exportação de imagens)
